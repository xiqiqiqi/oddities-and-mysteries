# 词典

这里放三类共享词典：

- `channels.yml`：频道，决定条目进入哪个站点。
- `types.yml`：内容形态，只作为筛选属性。
- `tags.yml`：标签，用于跨频道关联。
- `collections.yml`：专题，可以跨频道。

## 规则

1. `channel` 只能有一个，且必须是 `channels.yml` 里的 id。
2. `type` 可以有多个标签，但条目本身只写一个主类型。
3. 新增标签前先查重，避免「水怪」和「湖怪」并存。
4. 频道注释只用于页头、卡片元信息和页脚，不在正文里重复。
5. `hoaxes` 目前是 `future` 状态，等内容超过 50 条再启动。
