# 反馈与修正通道（无固定修正窗口）

> 2026-11-17 决定：**不设“两周修正窗口”**。发布后不进入倒计时观察期，也不承诺 24/48 小时 SLA；所有反馈统一走内容仓 GitHub Issues，按常规维护节奏修正。站点始终在线。

## 反馈入口

- 唯一入口：`https://github.com/xiqiqiqi/oddities-and-mysteries/issues/new?template=correction.md`
- 标题前缀：`[correction]`
- 模板：`.github/ISSUE_TEMPLATE/correction.md`，包含条目、页面 URL、语言、问题类型、位置、依据、期望
- 站内入口：六站页脚“关于 → 报告内容问题”（中英同步），直接跳到上述模板

## 处理方式

| 问题类型 | 处理 |
|---|---|
| 事实错误（日期、人名、地点、数字、引语） | 核实来源后直接 hotfix；改完重跑事实台账与门禁 |
| 图片缺失、破图、许可/署名错误 | 无法确认许可的图先下架，再补图或替换 |
| 断链、404、导航错误 | 修完跑 302 页线上检查 |
| 错字、语法、标点、排版 | 合并到常规批量修正 |
| 风格/改写建议 | 记录评估，不承诺排期 |

## 记录

- 所有已处理反馈写入 `research/correction-log.md`，记录编号、条目、问题类型、核实结论、修正 commit、上线时间。
- 不设窗口关闭日期，不生成窗口关闭报告。
- 发布不因“等待窗口”而延迟；发现系统性问题时回滚到上一个可用 tag，修复后重新发布。
